# Product Scope

## Positioning

AIDM replaces or assists a human DM/KP for lightweight online TRPG sessions. It focuses on coherent scenes, enforced turns, persistent facts, and low-cost availability.

## First Shippable Version

- Browser room with transcript, room state, player roster, and memory view.
- Deterministic local GM for demos and tests.
- Optional OpenAI Responses API narration.
- Local persistence.
- Turn-based multiplayer flow.
- Dice/check engine.

## Later Versions

- Postgres or SQLite persistence.
- Embedding-backed vector memory.
- Scenario marketplace and paid room cards.
- Image generation for NPC portraits and scene stills.
- Pre-generated video loops after room/scenario setup.
- Voice input/output and lip-sync avatars.
- Replay and battle report export.
