# AIDM 400+ Product Requirements

This library expands the product roadmap into 400+ acceptance-ready requirements. Each item is intentionally written as a product capability or major requirement area, not as a tiny implementation task.

Format contract:

`| REQ-001 | Title | Goal | Main Acceptance Criteria | Version/Module Tags |`
