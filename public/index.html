Product guide

Run the table without guessing

  1. Open a room Create a room with a title, tone, and table language, or paste an existing room ID. The URL becomes the invite link.
  2. Create characters Players join from the roster panel with species, class, archetype, and point-buy attributes.
  3. Begin the scene The host starts after at least one player joins. The scene card shows objective, threat, and clue clocks.
  4. Act or chat Use Action for turn-moving declarations and Chat for table talk. Roll mode controls normal, advantage, or disadvantage checks.
  5. Read the encounter During combat, check enemy HP, defense, tactical intent, and recent combat log entries before choosing the next action.
  6. Use voice playback Turn Voice on to read new transcript entries aloud. Each author gets a stable speaker profile.
  7. Build replay Use Replay after a scene to summarize chapters, highlights, and remembered facts.

Rooms

Create a new room for a session or reopen one by ID. The room URL carries the ID for quick sharing.

Characters

Species and class establish identity, while attributes feed derived stats such as HP, defense, and initiative.

Actions And Chat

Actions go through version-checked state updates. Chat adds conversation without spending the active turn.

Combat

The encounter panel shows enemies, tactical intent, status changes, damage, and recent resolution logs.

Voice

Browser speech plays immediately at no cost. eSpeak NG and Piper are the documented open-source local provider targets.

Asset Library

The asset preview reads checked-in SVG assets and generated raster sheets for scenes, character tokens, props, and marketplace art.

Memory Evaluation

AIDM includes a long-memory evaluation path so changes can be checked against campaign-history datasets.

npm run eval:memory

The 16-hour gate reports recall@5 and mean reciprocal rank. Use it after memory or retrieval changes, then compare results with docs/EVALUATION.md.
