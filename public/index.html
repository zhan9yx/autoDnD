牌桌指南

不用猜，也能顺畅开团

  1. 打开房间 创建房间时选择标题、风格和牌桌语言，或粘贴已有房间 ID。URL 就是邀请链接。
  2. 创建角色 玩家在名单面板中选择种族、职业、角色定位和点数分配。
  3. 开始场景 至少一名玩家加入后，主持人可以开始。场景卡会显示目标、威胁和线索进度。
  4. 行动或聊天 行动会推进回合；聊天用于牌桌交流。掷骰模式支持普通、优势和劣势。
  5. 阅读遭遇 战斗时先查看敌方生命、防御、战术意图和近期战斗日志，再决定下一步。
  6. 使用语音播报 打开语音后，新日志会自动朗读。每个发言者都有稳定的声线配置。
  7. 生成战报 场景推进后，用战报把章节、高光和记忆事实整理成摘要。

房间

创建新房间或用 ID 重开旧房间。房间 URL 可以直接分享。

角色

种族和职业决定身份，属性会影响生命、防御、先攻等派生数值。

行动与聊天

行动会经过版本校验并更新状态；聊天只记录交流，不消耗当前回合。

战斗

遭遇面板展示敌人、战术意图、状态变化、伤害和近期结算。

语音

浏览器语音可以零成本即时播放。每个角色会保留稳定声线。

场景画面

牌桌会根据当前剧情自动匹配场景画面、收获和氛围音。
